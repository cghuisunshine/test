Which explosion came first?

Two spaceships pass each other and two explosions go off. Depending on which ship you ride in, a different explosion happens first, and both answers are correct.

The setup

Let both ships have rest length L, and let A move at speed v relative to B. Write

β=vc,γ=11−β2.

Explosion x₁ happens when A's tail passes B's nose. Explosion x₂ happens when A's nose passes B's tail.

In B's frame

Put B's nose at x=0 and its tail at x=L. A moves in the +x direction and is contracted to length L/γ.

Event 1 is A's tail passing B's nose. Call that x=0,t=0. At that moment A's nose is at x=L/γ.

Event 2 is A's nose reaching B's tail. The nose is at L/γ+vt, so setting that equal to L gives

t2=L(1−1/γ)v.

Because γ>1, this is positive, so in B's frame x₁ comes first:

ΔtB=L(1−1/γ)v,ΔxB=L.

Transforming to A's frame

A moves at +v relative to B, so the Lorentz transformation for the time difference is

ΔtA=γ(ΔtB−vΔxBc2).

Substituting B's values:

ΔtA=Lv[γ−1−γβ2].

Since γ(1−β2)=1/γ, the bracket equals 1/γ−1, so

ΔtA=−L(1−1/γ)v=−ΔtB.

The sign is negative: in A's frame x₂ happens first, and by exactly the same amount.

Checking directly in A's frame

Now B moves at −v and is contracted to L/γ. Put A's tail at x′=0 and its nose at x′=L.

Event 2 happens at t′=0, when A's nose meets B's tail. B's nose is then at L−L/γ, and it reaches x′=0 at

t′=L(1−1/γ)v,

which is event 1. This matches the Lorentz transformation.

Why the order can flip

The order depends on the sign of Δt−vΔx/c2. For some speed below c to flip that sign, you need

cΔt<Δx,

which says light can't travel from one event to the other in time. Test it with B's numbers:

cΔtBΔxB=1−1−β2β<1.

This holds for every 0<β<1, because it is equivalent to (1−β)(1+β)>(1−β)2, which reduces to 1+β>1−β.

So the invariant interval

s2=Δx2−c2Δt2>0,

and the events are spacelike separated. Every observer computes the same s2.

If instead cΔt>Δx (timelike separation), the term vΔx/c2 could never outweigh Δt for any v<c. Every observer would agree on the order, which is why cause always precedes effect.

A worked example

Take v=0.6c, so γ=1.25 and 1−1/γ=0.2.
